# iot-based-smart-home-meter
An IoT-based smart home meter is an intelligent, connected device that replaces traditional electricity meters to measure, record, and transmit power consumption data in real-time. Using technologies like Wi-Fi (ESP32/ESP8266), sensors (PZEM-004T, ZMPT101B), and cloud platforms, these meters provide users with instant data via apps, enabling remote monitoring, automated billing, and energy-saving insights. 


Key Features and Capabilities:
Real-time Monitoring: Tracks electrical parameters such as voltage, current, power, and energy consumption (kWh) instantly.
IoT Connectivity & Remote Access: Data is transmitted via Wi-Fi or cellular networks, allowing homeowners to monitor consumption via mobile apps or web dashboards from anywhere.
Automatic Billing & Data Logging: Eliminates manual reading by sending data directly to utility providers and storing logs on platforms like Google Sheets.
Prepaid Functionality: Features advanced options for prepaid recharges, allowing users to pay for electricity in advance, often with theft detection alerts
